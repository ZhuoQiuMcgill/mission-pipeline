Memory that travels

Everything the process records lives in .mission-pipeline/: a SQLite skeleton connecting the run chain and checks, with Markdown leaves for words, decisions, cards, reports and summaries. Products live in git. Copy the folder while idle; any harness continues from the same memory.

What the user sees

“Why isn't it done?”
mp read blocked — block reason and next step.
“Explain X”
mp read show <kind> <id> — layer 2 for X.
Evidence
mp read leaf <id> — layer 3.
The tree
