# WI-13 An unsupported repository format or content transform, or git objects a step needs are missing

The Secretary handles this page.
For an existing escalation, route a PM-class choice with `needs-pm` / `ask-pm` through `mp sec decide <escalation> ...`.
For a question without an escalation, use `mp sec ask-pm "<question>" [--about <notice or item id>]`; the PM answers with `mp pm reply <id> "<text>" [--words W-n]`, visible in `mp sec next` / `mp sec wait`.
The PM decides on recorded words or asks the user under F-3; the PM runs the words-dependent `mp pm` actions below.

## Trigger and evidence

- At a dispatch or a delivery, `mp` found that the repository uses a content transform it does not support; git or LFS objects the step needs are not present locally (a partial or shallow clone, LFS objects not fetched); or LFS pointers with extension lines.
- Evidence: the objects or paths, the format or transform found.
- A commit the memory names that is missing after a copy or move is WI-30.

## Default action already taken

Only that dispatch or delivery does not run; everything else goes on. `mp` never fetches anything.

## Options and outcomes

1. The authorized agent fetches the objects, or the PM arranges access only the user has (`git lfs fetch`, or completes the partial clone) → the step is ready again in `mp sec next`.
2. Have the task avoid those paths (a PM plan batch that asks for it: `mp pm plan submit <mission> --file <plan.json> --words W-<n>`), or the PM arranges for the user to handle those paths.

## How to choose

Missing objects → 1; a transform or format that cannot be supported → 2.

## When to send to the PM

Use the escalation's `ask-pm` option if it has one; otherwise record the question with `mp sec ask-pm "<question>" --about <notice or item id>`. The PM decides on the words or asks the user.
When the user has to run a command.

The safety floor is never an option: stops stay in force; nothing unproven is called proven; no forced rewrites (reset, forced checkout) in the user's worktrees; no deletion of the user's data.
