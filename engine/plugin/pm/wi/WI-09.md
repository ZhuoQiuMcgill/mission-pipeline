# WI-09 Budget block, quota wait, or a seat's model not available

## Trigger and evidence
- Budget block (only with a money limit): the remaining budget cannot start any necessary next step; or the metering proxy refused a request at the limit and ended a seat.
- Quota wait: a seat would be cut off by the account's quota mid-way, so the program waits for the reset before dispatching it.
- Model not available (notice `model-unavailable`): a seat's model is retired or not in this login's plan. Claude Code refused it (its message is in the notice: "There's an issue with the selected model ... It may not exist or you may not have access to it"), or the model service answered 404 not_found_error. The notice names the seat, its configured model and the message.

## Default action already taken
Budget block: with work in flight, wait for its reservations to be released; without, the mission is "budget-blocked": a snapshot, risk list and reason are made, and no paid seat starts. Quota wait: wait, layer 0 shows the reset time; work not needing that quota goes on. Model not available: the attempt ended as an environment failure (a refused request is not charged); the automatic retries fail the same way until that seat's model changes, and when the lineage's retries run out it is exhausted (WI-08). Other seats and missions go on.

## Options and outcomes
1. Raise the limit, or make it unlimited: `mp spend-limit <mission> <amount|unlimited>` (a money amount needs self-check item 9 to pass).
2. Close as out of budget: `mp close <mission> --mode with-risk` (not available in the engine yet; mp says so).
3. Only finish work already in flight → no new paid seats.
4. During a quota wait, switch models: `mp model-config set <seat> --model <model>` → seats started later use it; switching models invalidates no conclusion.
5. Model not available: switch that seat to a model this login can use, `mp model-config set <seat> --model <model>`, or every seat at once, `mp model-config set all --model <model>` → the next retry of that seat runs it. A model is any Claude model id (`claude-opus-5-5`, a dated snapshot such as `claude-sonnet-4-5-20250929`) or an alias (`opus`, `sonnet`, `haiku`, `fable`), which follows Claude Code's current model of that family. If the lineage was exhausted meanwhile, ask for one more round under WI-08.

## How to choose
Spending is the user's decision: give the user the remaining budget, reservations in flight and the estimate, then follow their words. Model not available: propose the current model of the same family (the alias, e.g. `sonnet` for a retired Sonnet), with the reason (Claude Code's message); check `mp model-config show` for other seats on the same model and offer `all` when every seat should move.

## When to ask the user
Always (spending and model choice are the user's decisions). For a model that is not available, a same-family replacement can be proposed with the reason, and applied once the user agrees.

The safety floor is never an option: stops stay in force; nothing unproven is called proven; no repository hooks or forced rewrites in the user's worktrees; no deletion of the user's data.
